Getting connected

Three steps, about 10 minutes

Create a connection

Sign up for Ask DB and pick your database type. You get a personal connector token.

Run the connector

One command on any computer or server in your network that can reach the database. Available as a Docker image and as apps for Windows, Linux and macOS.

Ask

Once the connector is up, the app shows 🟢. Ask your first question.

docker run -d -e CONNECTOR_TOKEN=… -e DB_DSN=… askdb/connector
Ask DB6
Security

Data is only read. Never changed

1

Checked on the server

A single SELECT only. Updates, deletes and schema changes are rejected.

2

Checked again in the connector

The same rules inside your network. Even a compromised server can’t change your data.

3

Read-only session

The database connection is opened in read-only mode.

To be honest: the question, the table structure and the result pass through our server and the AI model; otherwise the AI can’t write the query. Traffic is encrypted. The AI never sees name, email or phone columns, not even as sample values.
